# FBA №16 — проверка реального HTML в Nodul Development

Дата проверки — 24.11.2026, МСК.

## Результат

Один контролируемый `Run once` на Development v25 завершился ошибкой через 14 секунд после четырёх операций. Триггер `Only Created (new_file)` поймал файл, созданный после запуска. Входной фильтр пропустил заявку из изолированной папки. Узлы Drive и N00 скачали и прочитали 734 байта JSON. Узел N01 завершился с `WRONG_FOLDER: verified trigger parent differs from pilot folder`. Родительская папка из события Drive отличалась от фиксированного параметра `pilot_folder_id` в N01.

Сборка и сверка проведены в интерактивной сессии ChatGPT Work. После создания файла Nodul автоматически выполнил четыре операции до ошибки N01. Событийная задача Work в прогоне не участвовала.

## Откат и условие следующего прогона

Исходный снимок Development v23 доступен в истории версий. В v27 восстановлены исходная папка триггера и исходный фильтр. Outlook оставлен на заблокированном маршруте, Active выключен, Prod не развёрнут. Производственные сценарии, Sheets, GAS и Telegram не затрагивались.

Для нового контролируемого запуска нужно согласовать временную замену `pilot_folder_id` в N01 и проверить по графу остальные ссылки на папку QA. Проверки метаданных, идентификаторов заявки и SHA-256 должны действовать. Перед производственным использованием остаётся подтвердить полный маршрут Nodul на реальном HTML и отдельно проверить обработку его результата в Work.

## Повторный прогон после согласования N01

В Development v28 параметр `pilot_folder_id` временно направлен в изолированную папку. Проверки N01 сохранены. Один `Run once` запущен в 13:00:46 МСК. После появления кнопки остановки в Drive создан один новый файл заявки с прежними проверенными данными и именем по протоколу. Предыдущий файл заявки переименован для сохранения истории. HTML-кандидат не менялся.

Запуск остался в очереди с нулём операций. Через 1 мин 20 с отменён. В истории подтверждено состояние «Отменено», операций 0. Файл результата в Drive отсутствует. Nodul не начал обработку нового события, поэтому исправление привязки N01 в этом прогоне не было проверено исполнением. История не показывает, почему событие не дошло до триггера. Геометрия и SHA-256 внутри Nodul остаются непроверенными. Тестовый финал не создан.

Конфигурация восстановлена из v27 в v30. Сверены исходный фильтр, папка и режим Only Created триггера. Active выключен, Prod не развёрнут, маршрут Outlook остался заблокирован. Следующая диагностика требует проверить готовность подписки Drive до создания файла и повторить один контролируемый запуск.

## Диагностический запуск в 14:22:58 МСК

Использован сохранённый тестовый снимок v28. В редакторе подтверждены приватная папка и `Only Created`. После появления признака работающего узла №17 новый файл заявки загружен в Drive из исходных байтов JSON. Предыдущая заявка архивирована переименованием. Сценарий получил событие, прошёл N01 и завершился ошибкой через 37 секунд после 11 операций.

Узел N03 вернул `CANDIDATE_WRONG_FOLDER`: `verified_candidate_parent_id` не совпал с `pilot_folder_id`. Первый параметр вычисляется по результату списка файлов узла №28 с поиском по ID кандидата. Нужно проверить область поиска №28 и фактический родительский ID, возвращаемый его формулой. Причина расхождения внутри этой связки пока не подтверждена. Nodul не дошёл до SHA-256 и геометрии. QA-результат и тестовый финал отсутствуют. HTML не менялся.

Настройки сценария не сохранялись заново. В редакторе повторно открыта базовая v30. Active выключен, Prod не развёрнут, маршрут Outlook заблокирован.
