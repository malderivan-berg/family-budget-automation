# FBA №16 — проверка реального HTML в Nodul Development

Дата проверки — 24.11.2026, МСК.

## Результат

Один контролируемый `Run once` на Development v25 завершился ошибкой через 14 секунд после четырёх операций. Триггер `Only Created (new_file)` поймал файл, созданный после запуска. Входной фильтр пропустил заявку из изолированной папки. Узлы Drive и N00 скачали и прочитали 734 байта JSON. Узел N01 завершился с `WRONG_FOLDER: verified trigger parent differs from pilot folder`. Родительская папка из события Drive отличалась от фиксированного параметра `pilot_folder_id` в N01.

| Проверка | Результат |
|---|---|
| Исходные данные | Реальная выгрузка Apps Script, схема `report_data` 2.0 |
| Заявка | `fba_layout_request` 2.0, попытка `a01`. Сверены имена, связь с кандидатом, родительская папка и числовое подтверждение |
| Числа в анализе | 7 проверено, 0 нарушений |
| Числа в HTML | 192 проверено, 0 нарушений |
| Скачивание HTML из Drive | 39 911 байт, побайтное совпадение подтверждено |
| SHA-256 скачанного HTML | `839afd64b86a8e7d5f036e2ab7e95159d32fcd594f1d3065e49919a555905014`, совпадает с заявкой и файлом подтверждения |
| SHA-256 внутри Nodul | Узел сверки кандидата не выполнялся |
| Геометрия на 320, 375, 390, 430, 768 px | Браузерный узел не выполнялся ни на одной ширине |
| Результат в Drive | `VALIDATED`, `REPAIR` и `EXCEPTION` отсутствуют. Тестовый финал не создан |
| Замечания к HTML | Данных браузерной диагностики нет. Кандидат сохранён с исходными байтами |

Сборка и сверка проведены в интерактивной сессии ChatGPT Work. После создания файла Nodul автоматически выполнил четыре операции до ошибки N01. Событийная задача Work в прогоне не участвовала.

## Откат и условие следующего прогона

Исходный снимок Development v23 доступен в истории версий. В v27 восстановлены исходная папка триггера и исходный фильтр. Outlook оставлен на заблокированном маршруте, Active выключен, Prod не развёрнут. Производственные сценарии, Sheets, GAS и Telegram не затрагивались.

Для нового контролируемого запуска нужно согласовать временную замену `pilot_folder_id` в N01 и проверить по графу остальные ссылки на папку QA. Проверки метаданных, идентификаторов заявки и SHA-256 должны действовать. Перед производственным использованием остаётся подтвердить полный маршрут Nodul на реальном HTML и отдельно проверить обработку его результата в Work.
